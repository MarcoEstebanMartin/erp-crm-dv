Estructura Unificada de Archivos de Prueba y QA - ERP-CRM DV
==========================================================

Esta carpeta centraliza todos los insumos utilizados para pruebas locales, demostraciones y control de calidad.

Propósito de las subcarpetas:

1_listas_precios/
   Guardá acá las planillas Excel (.xlsx) con productos, costos y listas de precios de ejemplo para probar la importación y actualización de catálogos.

2_imagenes_productos/
   Reservado para imágenes o mockups de productos (.png, .jpg) para validar la gestión y carga de imágenes vinculadas a los SKUs.

3_documentos_compras/
   Para PDFs de facturas de compras de proveedores, gastos de vehículos, repuestos o seguros para probar el escaneo OCR y el módulo de flotas.

4_iva_afip/
   Guardá acá los subdiarios de IVA generados y los archivos de exportación .txt / .zip oficiales para validar frente a AFIP o con tu contador.

5_credenciales_test/
   Contiene el listado rápido de usuarios y contraseñas de simulación local para preventistas, administradores y depósito (ver credenciales.txt).
